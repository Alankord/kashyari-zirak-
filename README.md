# SmartPOS — دابەزاندنی .exe لە ڕێگەی GitHub

ئەم فۆڵدەرە پڕۆژەیەکی Electron ـە کە پرۆگرامەکەت (`index.html`) دەگۆڕێت بۆ پڕۆگرامێکی ڕاستەقینەی ویندۆز (.exe). GitHub خۆی بە خۆکارانە (Actions) فایلی .exe دروست دەکات — پێویست ناکات هیچ شتێک لەسەر کۆمپیوتەری خۆت دابمەزرێنیت.

## هەنگاوەکان

### ١. دروستکردنی ڕیپۆزیتۆری نوێ لە GitHub
- بڕۆ بۆ github.com و لۆگین بکە (یان هەژمارێکی نوێ دروست بکە، بەخۆڕاییە).
- کلیک لەسەر **New repository** بکە.
- ناوێک بۆ بنووسە (نموونە: `smart-pos`) و **Public** هەڵبژێرە → **Create repository**.

### ٢. بارکردنی فایلەکان
لە پەڕەی ڕیپۆزیتۆرییەکەت:
- کلیک لەسەر **Add file → Upload files** بکە.
- هەموو ئەم فایڵ و فۆڵدەرانەی ژێرەوە ڕاکێشە (drag & drop) بۆ ئەو پەڕەیە، بە هەمان پێکهاتەی فۆڵدەر:
  - `index.html`
  - `main.js`
  - `preload.js`
  - `package.json`
  - `.gitignore`
  - فۆڵدەری `.github/workflows/build.yml`
- لە خوارەوە **Commit changes** بکە.

> تێبینی: GitHub لە وێبسایتەکەیدا ڕێگە بە بارکردنی فۆڵدەری تەواو نادات، بۆیە باشترین ڕێگا بەکارهێنانی **GitHub Desktop** یان کۆمانی `git` لە کۆمپیوتەرەکەتە بۆ push کردنی هەموو فۆڵدەرەکە بە یەکجار. ئەگەر بەکارهێنانی git نازانیت، دەتوانیت فایلەکان یەک بە یەک باربکەیت (پێویستە فۆڵدەری `.github/workflows/` دروست بکەیت لە کاتی بارکردنی `build.yml`، بە نووسینی `.github/workflows/build.yml` وەک ناوی فایل لە کاتی upload).

### ٣. چاوەڕوانی دروستکردنی خۆکار
- پاش commit کردن، بڕۆ بۆ تابی **Actions** لە سەرووی ڕیپۆزیتۆرییەکەت.
- دەبینیت کارێک (workflow) بە ناوی **Build Windows EXE** دەستی پێکردووە. چاوەڕێی بکە تا سەوز ببێت (٢-٥ خولەک دەخایەنێت).

### ٤. دابەزاندنی فایلی .exe
- کاتێک کارەکە تەواو بوو، لەسەری کلیک بکە، لە خوارەوە بەشی **Artifacts** دەبینیت بە ناوی `SmartPOS-Windows`.
- کلیکی لەسەر بکە بۆ دابەزاندن — فایلێکی zip دەبێت کە تێیدا فایلی `.exe` (بۆ ڕاستەوخۆ ڕاکردن — portable) و سێتەپێکی `.exe`ی تری هەیە (بۆ دامەزراندن بە شێوازی ئاسایی).
- ئەم فایلانە دەتوانرێت لەلایەن هەر کەسێکەوە دابەزێنرێن و ڕابکرێن لەسەر ویندۆز، بەبێ پێویستی بە هیچ دامەزراندنێکی تر.

### ڕێگای زیاتر ئاسان (بۆ ڕیلیزی فەرمی)
ئەگەر دەتەوێت لینکێکی جێگیر بۆ دابەزاندن دروست بکەیت (بۆ نموونە `Releases` لاپەڕەی ڕیپۆزیتۆری)، لە GitHub تاگێک (tag) دروست بکە بە ناوی وەک `v1.0.0` — کارەکە خۆی بە خۆکارانە فایلی .exe زیاد دەکات بۆ بەشی Releases، بۆیە هەر کەسێک بێ ئەکاونتی GitHub دەتوانێت دایبمەزرێنێت.

## ئاگاداری
- ئەم پرۆگرامە بە تەواوی ئۆفلاینە (وەک خودی HTML ـەکەت)، هیچ داتایەکی بەکارهێنەر بۆ هیچ سێرڤەرێک ناچێت.
- ئەگەر دواتر ویستت وێنۆچکەیەک (icon) بۆ پڕۆگرامەکە دابنێیت، فایلێکی `.ico` دروست بکە بە ناوی `build/icon.ico`، و ئەم دوو دێڕەیە بگەڕێنەرەوە بۆ `main.js` و `package.json`:
  - لە `main.js`: `icon: path.join(__dirname, 'build', 'icon.ico'),`
  - لە `package.json` لەژێر `"win"`: `"icon": "build/icon.ico"`
