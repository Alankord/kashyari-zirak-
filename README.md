# کاشێری زیرەک - SMART POS (Electron Desktop App)

سیستەمی فرۆشتنی زیرەک بۆ فرۆشگاکان - ١٠٠٪ ئۆفلاین

## 📥 دابەزاندن

### Windows
1. فایلی `کاشێری-زیرەک-Setup-1.0.0.exe` داببەزێنە
2. دووجار کلیک لەسەر بکە بۆ دامەزراندن
3. دوگمەی "Install" لێبدە

### macOS
1. فایلی `کاشێری-زیرەک-1.0.0.dmg` داببەزێنە
2. App-ەکە بکەڕە بە فۆڵدەری Applications

### Linux
1. فایلی `.AppImage` یان `.deb` داببەزێنە
2. بۆ AppImage: دووجار کلیک بکە
3. بۆ deb: `sudo dpkg -i kashyari-zirak_1.0.0_amd64.deb`

## 🚀 بەکارهێنان

```bash
# ١. دابمەزرێنە
npm install

# ٢. تاقیکردنەوە
npm start

# ٣. دروستکردنی فایلی دامەزراندن
npm run build-win    # Windows
npm run build-mac    # macOS
npm run build-linux  # Linux
```
